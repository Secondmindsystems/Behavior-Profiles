# Claim Boundary

This repository contains educational patterns, behavior profiles, and public-safe examples from Second Mind Systems.

These materials are intended to help readers understand and apply public-safe behavioral patterns for AI-agent work.

They do not grant runtime authority and do not replace human review.

## This Repository Does Not Contain

- enforcement guarantees
- security guarantees
- compliance guarantees
- runtime authority
- customer-validation claims
- product-market-fit claims
- private governance machinery
- private Second Mind architecture

## Explicit Exclusions

This public shelf does not expose or include private machinery, including:

- private architecture
- unpublished governance mechanisms
- private routing or scoring rules
- thresholds, proof formats, hooks, tokens, or release machinery
- non-public product implementation details

No private mechanism is required to use the public materials in this repository.

## Public Use Boundary

Use these materials as educational patterns and instruction-layer examples.

Do not treat them as:

- security controls
- compliance controls
- automated authority systems
- production validation
- customer proof
- product-market-fit evidence
- replacements for human review

For product-specific claims, use the product's current public page and claim-reviewed materials.
