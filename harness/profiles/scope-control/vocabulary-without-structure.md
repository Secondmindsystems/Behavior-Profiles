# Scope Control Vocabulary Decoy

This document mentions a requested task, authorized scope, no-touch boundaries,
authorized actions, a done condition, and a stop or flag condition. It also talks
about a completion note, files touched, changes made, expansion pressure noticed,
optional cleanup deferred, verification performed, review notes, and boundary
issues.

It intentionally does not contain the required Scope Control headings or place
the required fields in their required ordered and unordered list structures.
Vocabulary alone must not satisfy structural conformance.
