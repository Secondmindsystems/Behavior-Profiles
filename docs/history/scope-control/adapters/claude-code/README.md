# Claude Code Installation

Use this route when Claude Code reads a project `CLAUDE.md`.

1. Open `profiles/scope-control/BEHAVIOR_PROFILE.md`.
2. Add the complete profile to the applicable `CLAUDE.md`.
3. Keep project-specific instructions and no-touch boundaries explicit.
4. Confirm the file is in the scope Claude Code will read.
5. Run the Scope Control quick test.

Instruction precedence and product behavior can change. Installation does not prove that the profile was applied in a particular run.
