# Behavior Profile: Scope Control

**A free conduct contract for AI coding agents.**

You asked for one change. The agent completed it, then quietly expanded the task.

Scope Control asks the agent to make the task boundary visible before acting, stay inside authorized scope, and return a completion note afterward.

## What It Does

- reads back the requested task and authorized scope;
- names no-touch boundaries and allowed actions;
- separates required work from optional cleanup;
- flags expansion pressure instead of silently acting on it;
- returns a short completion note.

## What It Does Not Do

It does not block files, guarantee obedience, provide security or compliance, or replace human review.

## What the Free Package Includes

- complete installable Scope Control profile;
- AGENTS.md, Claude Code, and generic installation guidance;
- three pressure-test fixtures;
- quick test and explicit expected observations;
- PASS / FAIL / CONFUSED evidence template;
- package-integrity verifier;
- limitations and bypass disclosure.
