# AGENTS.md Installation

Use this route when your coding agent reads `AGENTS.md`.

1. Open `profiles/scope-control/BEHAVIOR_PROFILE.md`.
2. Add the complete profile to the applicable `AGENTS.md`.
3. Place it at the repository root for repository-wide conduct, or in a nested `AGENTS.md` for a narrower subtree.
4. Check instruction precedence for your agent before trusting the installation.
5. Run the Scope Control quick test.

AGENTS.md is the instruction surface. The Behavior Profile is the conduct contract placed inside it.

Installation does not prove obedience. Record an observed test result separately.
